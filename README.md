# Yalla Español (يلا إسباني)

Spanish course for Arabic speakers. Static web app plus Cloudflare Pages Functions backend.

- `public/`: static site, current release 401 (app bundle, lexicon, direct and reverse dictionary bundles, fonts, images).
- `functions/`: Pages Functions (accounts, sync, curriculum payloads).
- `wrangler.jsonc`, `prepare.mjs`: Cloudflare Pages config and the step that copies an approved release into `public/`.

Not included: `audio-sprites/` (about 1.2 GB of packed dictionary audio, served from the live site; `public/audio-sprites/index382.json` maps each entry to a sprite file and time range; the sprites are NOT in this repo, so they are not a GitHub-restorable part of the backup), older release bundles, and all secrets. API tokens, email keys and OAuth secrets are configured in Cloudflare, never in this repo.

Live site: https://yalla-espanol.pages.dev/


## Audio in this repo
`public/assets/audio` (12,647 clips) and `public/audio` (1,591 clips) are included. Grammar clips are named `g403-<hash>.mp3` and are generated by `grammar-src/gen.py`.
